# 📚 Library Management System

A Python-based Library Management System developed as part of 
Software Quality Engineering (SQE) Lab Assignment 4.

## 📋 Project Description
This system allows users to register, login, borrow and return books.
Admin functions include adding/removing books and viewing transactions.

## 🗂️ Project Structure
SqeLabProject/
├── main.py          # Main entry point
├── auth.py          # Register & Login
├── library.py       # View, Search, Borrow, Return books
├── admin.py         # Admin functions
├── database.py      # JSON file read/write
├── test_project.py  # Unit tests
└── README.md

## ⚙️ How to Run
1. Make sure Python is installed
2. Open terminal in project folder
3. Run: python main.py

## 🧪 How to Run Tests
python -m unittest test_project.py -v
